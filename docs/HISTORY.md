# Project history and attribution

- December 14, 2025: last-edit date observed in the accompanying Google Doc.
- October 21, 2026: development of this research scaffold began. It must not be represented as code or research completed in 2025.

The original project was created by Olivia Iarmak for the Dell × NVIDIA hackathon described in her project notes. The original notebook used Gradio, text substitutions, Python rules, a simulated airport API, and keyword-based evaluation. It did not integrate a real ASR model, LLM, or NVIDIA API. The deck's live architecture was a proposed direction, not an implemented system.

The original `wer` function used sequence similarity, not word error rate. It is not carried into the evaluator. Accented-English degradation was deliberately programmed; it is not a measured fairness result.

The Google Doc, notebook, and deck were inspected with owner-authorized access. Private exports and personal material are excluded from this release. A cleaned archival copy of the original notebook remains a future task; this file records history, not an exact source archive.
