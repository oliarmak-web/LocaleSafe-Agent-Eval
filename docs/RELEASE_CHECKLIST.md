# Status

**Implemented:** offline scorer; local model collector; stage/paired diagnostics; service simulator; consent/duplicate guards; language/context/phrasing controls; tests and CI.

**Evidence:** single-turn pilot; closed-choice probe; direct-date cross-check; 1,800 workflow decisions; 2,880 initial handoff calls; 384 exploratory monitor calls; cached routing replay. Full autonomous dialogue and independent human review remain pending. [Findings](FINDINGS.md).

**Next:** independent reviews, live dialogue adapter, richer held-out families, repeated multi-model runs, uncertainty analysis, external reproduction.

**Before public release:** owner review of attribution/license; secret/history review; enable available security reporting/scanning. Repository visibility is a separate setting.

**Scope:** cultural competence, clinical safety, adoption, causal language effects and statistical significance are not established by the current studies.
