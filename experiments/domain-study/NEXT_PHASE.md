# Follow-up contrasts requiring independent review

Proposed research, not frozen collection or completed results. The first feasibility run uses six shared templates; it cannot establish cultural effects or production failure rates.

| Contrast | Hold fixed | Change | Outcome to inspect |
|---|---|---|---|
| Direct versus polite approval | Same verified caller, action, record and value | Native-authored request form, including an explicit approval anchor | Unnecessary clarification/refusal versus exact permitted completion |
| Understanding versus authorization | Same proposal, policy and language | Acknowledgment, explicit approval or genuinely ambiguous reply, separately adjudicated | Whether execution permission is invented; whether ambiguity triggers clarification |
| Number/date conventions | Same language, currency, geography and underlying value | Explicitly declared locale and matching representation | Canonical value fidelity versus downstream policy error |
| Proxy caller authority | Same words and relationship | Trusted verification status only | Clarification when unverified and completion when verified, without inferring authority from relationship |
| Industry terminology | Same intent and policy | Native term, English loanword or code-mixed phrase reviewed for equivalent meaning | Entity/operation preservation and specialist routing |
| Dictation cleanup | Same licensed audio and reviewed intended meaning | Raw ASR versus delivered edited text, with actual provider settings | Lost negation, correction, condition or scope versus harmless paraphrase |
| Voice interruption | Same approval and withdrawal | Recorded timing relative to transcript, agent decision and executor | Recognition delay versus stale-state execution; text replay alone cannot measure this |

Each contrast needs new versioned cases, independent language/domain review and an untouched validation set. Reviewer judgments must identify ambiguity rather than force a label. Register, script, language, nationality and geography are separate factors. The English competence screen and counterbalanced measurement checks remain requirements. Higher repeated call counts do not substitute for new independently authored situations.

Actual speech studies need licensed recordings, documented consent where applicable, human reference transcripts and reviewed intent. Product tests need free authorized access and recorded model/mode/settings. No paid API usage or private customer data is assumed. Native review and provider access must not be fabricated to make the research appear complete.
